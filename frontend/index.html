HOW IT WORKS

条件を決め、根拠を確認し、過去で検証する。

01 / DEFINE

分析条件を決める

銘柄・期間・変化率の閾値を指定します。保存した条件は、そのまま再利用できます。

02 / OBSERVE

状態と遷移を見る

状態間の遷移回数、推定した確率、価格系列を並べて、計算の根拠を確認します。

03 / VALIDATE

過去の各時点で検証する

その時点より前のデータだけで、翌営業日の状態を評価します。予測できない日も明示します。

研究・教育目的のツールです

投資助言や売買の推奨は行いません。確率は指定した過去データとモデルの仮定に基づく推定であり、将来の値動きや売買利益を保証しません。観測の少ない状態は、無理に確率を補わず「推定不可」として表示します。
