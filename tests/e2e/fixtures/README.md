# Offline E2E prices

`prices.csv` contains artificial values, generated by `generate.py` on the
existing engine's XTKS calendar. It contains no downloaded market prices.
The first 60 states rise by 1%; later states alternate between flat/up/down.
This supplies both unestimated analysis rows and scored/skipped backtest days.

The CSV is mounted read-only into the explicit fixture deployment. Its provider
is disclosed as `FIXTURE`; the production provider remains YFinance.
